# 信息设计与图表

来源：assembly/0715-01/深度对比报告.md「信息设计与图表」7 条 + 查漏补缺 2 条（微图形词汇、时间线卡），冲突处以 assembly/0715-01/修改单-04.md 勘误节裁决为准。

## 适用时机

装配流程第 2 步（分段方案）里为每段选证据形态、选图表组件时读；装配后自检「哪段只有文字 chip」时再过一遍。核心问题只有一个：**这个论点的图形证据是什么？** 答不上来的段落视为装配未完成。

## 规则

### R1【sev5】比喻词必须落成图形，纯文字 chip 顶替 = 装配未完成

逐字稿出现空间/数量比喻词（墙、潮、出清、级联、飞轮、循环、溶解、蒸馏）时必须图形化。选件映射：

| 比喻词 | 组件（已建） | 用法要点 |
|---|---|---|
| 墙 / 硬性壁垒 | BrickWall | 错缝砖块逐块弹入，中央嵌「中文·英文」标签 |
| 批量 / 出清 / 潮 | UnitMatrix | 默认 3 组 5x8 红方阵表「批量」；**waffle 比例模式**：groups=1 rows=10 cols=20（200 格）+ fillRatio=0.73 表「73%」，点亮格语义色、未点亮格灰暗常驻 |
| 仿品 / 被蒸馏 / 级联 | CloneCascade | 源图标 + 3 个复制体依次淡入 + 警示 chip |
| 飞轮 / 增长循环 | Flywheel | 线框 HUD 感，环体宜细不宜粗实（色彩细节见 texture.md） |
| 闭环 / 循环流程 | LoopDiagram | 环体+中心胶囊必须吃 enterAt opacity 门控，别从 Sequence 第 0 帧白给（修改单-04 B6 勘误） |

### R1.5【seg02 过审沉淀】一个图形载体跟口播多段变形，禁止拆成孤立元素

- 比喻图形要「跟着口播演」：占位（灰）→ 变化（语义色逐格点亮，与数字滚动同拍）→ 反转（少数格换色）——占位制造期待、变化承载数字、反转承载转折，图形自己讲故事。基准片 200 格 waffle 三拍复用同一载体（灰阵「200多家」句→随 73% 滚红→「18家」句 18 格变绿）。
- 反面：同一信息拆成「先出数字、再出点阵、再出 chip」三个孤立元素，因果感全无。
- 组件支持：UnitMatrix `stages`（placeholderAt/fillAt/fillFrames/greenAt/greenCount）。

### R1.6【seg04 过审沉淀】机制类比喻翻译成空间关系与运动，判词零复读

- 「能力缺口」= 黄卡咬在蓝卡缺口上的**位置关系**；「被取代/归零」= 新元素顶入、旧元素旋转坠落出画的**物理动画** + 一个红描边小标注——比喻词优先找「谁取代谁/谁挤掉谁」的物理动作，静态摆卡是下位选择。
- **判词零复读**：同一判决只允许一个载体——卡+大字+印章三连说同一件事（v4 归零段旧病）= 错；动画本身在说话时，文字判词降级为小标注。
- **判死要两层，别只贴不褪**（seg05 §七 帧级校验）：「归零/判死」的数字载体从撞入起**持续褪色灰化 ≈2s**，等它可见地「死了」之后小标注/贴纸才落下；只落贴纸不做数字褪色 = 判词悬空（贴在还活着的数字上，因果读不出）。小标注载体规格走 specs.md §2「判词小标注 ZeroTag」。
- 组合道具做成 rig 一次进场，戏在道具上演（进场一次、动画只动部件）。

### R2【sev5】每个 CASE 段至少 1 帧产品 UI 证据，禁止抽象图形代表具体产品

优先级：真实录屏 > 截图 > UI 模拟卡兜底。装配前素材清单加一项「每个案例收集 1 张产品截图或 5s 录屏」。录屏装载、UI 模拟卡做法、A 级素材接管规格见 broll.md。

### R3【sev4】大数字用三层结构，禁止裸叠白板亮面

- 三层结构：上 kicker（如「2022.10·VALUATION」）→ 中间语义色大数字 → 下方中文注释行（如「估值 15 亿美金·AROUND $1.5B」）。中文注释行不能弱到不可见（v3 反例：中文比英文还暗）。
- 放置：大数字、图表、Stamp 默认归位左区暗底；确需进右区亮面时组件必须自带深色底板，用 SURFACE.darkPlate + 1px 描边。

### R4【sev4】「一反一正」对比段做 VS 双面板，两侧各配一个图形证据

- 结构：红负绿正分置左右两区即可表达 VS，不需要中央徽章，避开人物区。
- 正例侧优先用上升折线：CurveOverlay 绿色 draw-on 约 1.5s，节点依次点亮，末端挂人物 chip / 绿 Stamp——**涨势即论点**；反例侧配 CloneCascade 或红色方阵。
- VS 决算升格靠**红绿镜像描边决算框**（非压暗）：两个镜像框坐左右侧区、**人物区留空不跨中、不压暗**（B 级压暗升格已被用户否决），升格感来自 hero 大 / 框 header 中 / chip 小三级字号落差 + 红绿镜像本身；chip **分批入框兑现口播**（红先满绿后满）、**空框先立再填**制造「你站哪边」的悬置、红绿 Breathe 相位错开。框规格见 specs.md §2「决算框 VerdictBox」（seg17 mini 实测），叙事时点见 narrative.md。

### R5【sev4】截图证据必须裁切放大到关键句可读，禁止整图缩放塞卡片

- 关键句字高 ≥32px（1080p，裁切放大目标档）；该段升级为 A 级素材接管 + stage2 punch-in 时关键句 ≥40px（A 级 punch-in 档；修改单-04 B4 勘误：引用类默认走 takeover，素材卡 ≥1100px）。三档语义（16 整卡准入 / 32 裁切放大 / 40 punch-in）见 specs.md §2。
- 荧光高亮只刷被引用那一句，句下贴黑底中文翻译 chip、随句子出现；头像+名字+蓝V 头部同步放大。
- 组件路径：TweetCard/QuoteDoc 的 cropZoom 模式（传关键句裁切区域，只渲染头部+关键句放大区）。

### R6【sev3-查漏】元素关系不能只靠邻近表达，每个论点段至少 1 处指示图形

- 因果/指向 → Connector；设问 → QueryBubble；涨跌 → TrendArrow；模拟点击 → 大号光标图形。
- 基准片平均每个论点段 ≥1 个指示图形，我们抽查 15 帧为零。三个微图形组件报告要求新建，装配前先确认 src/design/ 已有再引用。

### R7【sev3-查漏】多步结局事件用带日期的多节点时间线卡，禁止压成单 chip

- 叙述带时间推进的事件（收购→叫停→回购这类）用 TimelineEvents（已建，src/design/TimelineEvents.tsx）：横线生长 + 事件点依次亮起 + 结果 chip 挂点下方；每节点=语义色日期短语 + 状态图标 + 中文结论行，逐行 stagger 入场。

### R8【sev3】法规/行业论断配「来源+日期」micro-chip 行

- 底部横排 2-3 个来源 chip，每个=图标 + 名称 + 「'YY.M」日期或机构后缀，弱化配色（灰底金字），依次 stagger 入场。
- 至少给出一个带来源的量化数字，可信度层不能空（Chip 的 source 变体）。

### R9【sev2】信息 chip 一律带 16-20px 语义图标，禁止裸文字 chip

- 图标从「语义→图标」映射表取（法律→印章、数据→硬盘、权限→钥匙、风险→警示三角……），承担快速识别功能；基准片 chip 图标覆盖率近 100%，我们约一半。图标风格规范（lucide 线性、禁 emoji）见 SKILL.md 图标规范节。

### R10 图表选件速查（先按信息类型选件，再看规格）

| 信息类型 | 组件 | 适用场景 |
|---|---|---|
| 单个重锤数字 | BigNumber | 估值/比例/金额；spring 计数器滚动；恒配 R3 三层结构。滚动必须真滚（≥0.8s 可感知），名存实亡的 0.2s 滚动判不合格 |
| 多项排名/对比量 | BarChart | 数据条圆角；重点条换黄 + 顶部皇冠 chip，其余灰 |
| 趋势/增长论点 | CurveOverlay | 曲线直接叠素材或面板，draw-on 生长，右端点标注；VS 正例侧首选 |
| 红绿比分对垒 | ScoreBoard | 绿:红大数字比分，阵营决算段 |
| 自增强循环 | Flywheel | 「飞轮」比喻专用，线框感 |
| 流程闭环 | LoopDiagram | 「闭环/循环」概念图，注意 enterAt 门控（R1 表注） |
| 时间推进事件 | TimelineEvents | 多节点结局叙事（R7） |
| 比例/批量 | UnitMatrix | waffle 比例模式或多组方阵（R1 表） |

选件后仍要过 R3 放置规则（暗底/darkPlate）。
