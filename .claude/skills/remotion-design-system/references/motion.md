# 动效规则（入场 / 退场 / 分拍 / 持续动画）

核心心法：跟着口播一拍一拍演。一个复合信息拆成多个入场节拍，旧信息在话题结束时整组退场，章间留净屏呼吸。**元素一旦到位就完全静止**（2026-07-25 实测改写，见 §9）。反面模式（v3 教训）：「一次性贴上、永不退场」——全片单一滑入、高亮烤死在图里、Sequence 边界整帧硬切。

## 适用时机

装配流程中两处必读：
1. 逐 Scene 排元素 enterAt/exitAt 时（对 SRT 定时间点的那一步）；
2. 渲染前动效自检时（查退场、查白给、查静止主角）。

## 规则

### 0. 帧数一律「先秒后帧」，按合成实际 fps 换算【2026-07-16 校准教训】
- 所有动效时长先写秒，再乘合成 fps 得帧数；**禁止照抄别处的帧数口径**。
- 事故：tokens.ts 的 popInFrames=18 / stagger=14 是按 60fps 写的，合成实际 30fps → 全片入场慢一倍（0.6s）、stagger 拖 0.47s，是「PPT 感/拖沓感」的系统性来源。已校准为 9 / 7（@30fps ≈ 0.3s / 0.23s）。
- 本文件所有帧数均已按 30fps 口径标注；换合成 fps 时全部重算。
- **换合成 fps 连带清单（fps≠30 时逐项改，否则整套 30fps 校准失效）**：① `src/design/tokens.ts` 的 `MOTION.popInFrames`/`stagger`（现按 30fps=9/7，先秒后帧重算）；② 本文件所有帧数；③ specs.md §5「动效数值（30fps 换算后）」整表；④ `scripts/qc-master.sh` 元数据断言 `1920,1080,30/1`（L26-29，改成新分辨率@fps）；⑤ SRT→帧换算 `enterAt=秒×合成fps` 已按 fps 参数化，自动跟随、无需改。分辨率变化另连带 layout/specs 的三区与安全框像素。

按重要度排序。「证据」指 assembly/0715-01/深度对比报告.md 动效章及其 pair 图。

### 1. 每个元素必须有退场，禁止整屏一帧硬切【sev5】
- Sequence 结束前 ≥0.4s 开始用 `useExit(exitAt)` 退场：淡出 12-18 帧 + 轻微下移或 scale 0.98。
- 组件状态：motion.ts 的 `useExit` 即将补上；装配时先按此规范给每个收尾元素预留 exitAt，组件到位即接。

### 2. 章间净屏放章尾，概念名词对齐优先【sev5 + 修改单-04 裁决 B5/B13】
- 旧章元素全部退场后，留 1-1.5s 只有人物 + 字幕的净屏，再起新章。
- 裁决：净屏放**章尾**，不强求章首；当净屏时长与「新章概念名词主视觉对齐其 SRT 起点」冲突时，**概念名词对齐优先**（如 IMMUNE-03、DATA SOVEREIGNTY 必须卡在名词说出的那一句）。

### 3. 复合卡片至少拆 3 拍入场，每拍对准一个 SRT 词【sev5】
- 拍序：载体（卡片显影）→ 高亮/标注（scaleX 0→1 约 0.4s 扫过 + 翻译条弹出）→ 结论大字（砸落/盖章）。参考节奏：基准片推文段 4 拍走完全程 2.2s（21.3/22.5/23.1/23.5s 各对一个口播词）。
- kicker 先行：HeroText 已支持 `kickerEnterAt`（默认 enterAt−10 帧），kicker 比主字先行 0.3-0.5s，禁止 kicker + 大字 + 副标整体一次入场。
- 禁止把高亮、标注、翻译条预先烤进素材图——二段动画必须在 Remotion 里做（PhoneMockup/QuoteDoc 的 highlightAt 属性）。

### 4. 服役区间：同屏视觉主角只允许 1 个【sev4】
- 装配时给每个证据元素定「服役区间」；新主角入场前 0.3s，旧主角 `useExit` 退场。
- **⚠ 降级让位已废止（2026-07-25 逐帧实测）**：参考片**不做降级**——主角在整个 shot 内 0 位移、0 缩放、0 调暗，换层级时**整块直接 cut 掉**，不是先变暗腾位。唯一的「让位」动态是**新元素以 ~27% 亮度淡入登场**（约 4s 升到满亮），靠新件自己低调进场避免抢重心，而不是把旧件压暗。
- 渐进披露的正确形态：元素随口播逐条出现、**全部保持满亮**，段落结束整组齐退——「常驻」适用于同一话题内的全部件（不分主从），主角换人则整组清场重起。

### 5. build-up 不白给：enterAt 不早于对应 SRT 句【sev4】
- 除章节 kicker 外，任何元素 enterAt 必须落在其对应口播句的 SRT 区间内；禁止章首把后文元素提前挂上（v3 的 LOOP 圈提前 17s 白给）。
- 新章按叙事逐层搭建（参考基准片约 10s：章标签→大数字滚动→录屏卡→条目逐条进），每个元素等口播提到才出现。
- 陷阱（修改单-04 B6 勘误）：enterAt 门控必须覆盖组件**全部子元素**。LoopDiagram 曾只有 4 个节点吃 enterAt，环体和中心胶囊从 Sequence 第 0 帧就渲染——装配值对了照样白给。新图形组件验收时逐层查 opacity 门控。

### 6. 三档动效词汇，禁止全片单一入场【sev3】
- **⚠ 2026-07-25 实测收窄**：参考片 **95% 是纯淡入**（opacity-only，位置硬定位），全片未见位移滑入、缩放、打字机。唯二例外是**数字滚动**与**条形/线条生长**——它们是「过程本身就是信息」。旧「三档词汇」里的 **chip 滑入已废止**，改为纯淡入。
- 现行词汇表（按元素类型）：
  - 一切文字件（kicker/hero/清单/注脚/chip）= **纯淡入**，位移 ≤1% 画面尺寸或干脆为 0；
  - 大卡片/证据图 = 纯淡入（`usePop` 的 scale 0.95→1 可保留，幅度已够小）；
  - 数字 = 滚动（第 7 条）；条/线 = 生长；
  - 结论判词 = Stamp 砸落（保留，属「物理大动作」预算内，§11）。
- 同组子件错峰 **5-7 帧**（不是长错峰）；同屏**同一时刻只允许 1 个逻辑组在动**。
- 组件状态：`usePop` 已在 motion.ts（2026-07-16 补齐，13 帧 @30fps ≈ 0.43s），大卡片直接用。

### 6.5 动效词汇增补（2026-07-24 词级精读，0.1s 细扫实测 @30fps）

- **hero 进场 = 原位淡入 + 亮度爬升**（9-15 帧）：字符从暗灰渐亮到满色，**无位移、无缩放、无滑入**——「浮现感」取代「弹出感」；小元素淡入 3-6 帧，ghost 起点 ≈35-50% 透明度。
- **⚠ 交叉溶已废止（2026-07-25 逐帧实测覆盖 07-24 口径）**：实测**退场与下一组进场的重叠帧数 = 0**——参考片从不交叉溶，一律「整组退净 → 停 3-12 帧 → 下一组进」。话题重置时留白更长（2.5s 至 16.8s）。07-24 那轮把「B-roll 切点处画面自然溶接」误读成了 MG 交叉溶，勘误于此。
- **同位替换只保留一种**：同一个数字块内的**数值刷新**（$4.3T→945 这类，锚点与 label 不动、只换数值）。板→板、hero→hero 一律走「退净再进」。**字幕可先于版式 0.8s 换句**（声先行、图跟上）这条仍有效。
- **两种诞生法各有语义**：褒贬词**生即为其语义色**（金/灰直出）；「由虚到实」的概念走**先灰后亮**（数字分身 灰 ghost→提亮为白）——诞生动效本身讲语义。
- **数字滚动可从中间值起跳**（415→945，暗示「已经很高还在涨」），ease-out 前 70% 冲刺后段减速锁定（1.0-1.6s）；点阵/条形与数字是**绑定动画**同步填充，不是两个独立元素。
- **唯一放慢的动效是图表生长**（折线 ≈3s 左→右 draw-on）——需要「感受增长」才放慢，其余一律求快；条形图逐行生长单条 4-6 帧、~1s 全出。
- **退场整组走**：换章时清单连 kicker 整块同时淡出（6-15 帧），不逐条撤。

### 6.6 动效时长与曲线实测表（2026-07-25 逐帧测量，60fps 源，秒为准）

| 元素类型 | 秒 | @30fps 帧 | 缓动 | 过冲 |
|---|---|---|---|---|
| 大字标题进场 | 0.33 | 10 | ease-out（≈quad） | **无** |
| 大字数字进场 | 0.28-0.43 | 8-13 | ease-out | **无** |
| 正文/列表项淡入 | 0.52 | 16 | ease-in-out | **无** |
| 条形/线条生长 | 0.55 | 17 | ease-out | **无** |
| 整块 MG 组淡入 | 0.40 | 12 | **线性** | **无** |
| 数字滚动 | ~1.0 | 30 | ease-in-out | **无** |
| 退场（任意件） | 0.25-0.30 | 8-9 | — | **无** |

**三条纪律**：
1. **时长跟着信息量走**——字越大越快（0.33s，信息量小要立刻可读），过程量越慢（生长 0.55s、滚动 1.0s，因为过程本身要被看见）。禁一刀切。
2. **退场比进场快 2 帧**（实测中位：进 17f / 退 15f @60fps）。
3. **曲线分场合**：入场 ease-out、过程量 ease-in-out、整组切换线性。**全部零过冲**——6 实例 4 种曲线无一 spring 回弹，终值单调逼近后锁死。

**位移常量**：纵向进场位移 **≈1% 画高**（2160p 下 21px / 1080p 下 11px），横向 ≈0.7% 画宽。两个不同场景测得同值——是一套常量。**禁把位移放大到 5-10%**（模仿最易错的三点之一）。

### 7. BigNumber 必须滚出真实变化【sev3】
- 至少 3 位数字在滚动中变化、时长 1.5-2s（@30fps 即 countFrames 45-60，按第 0 条换算）；量级词（亿/B/M）放后缀，数值本体保持多位数（滚 125 而非 1.25，滚 10000 万而非 1 亿）。
- 叙事有递进时用两段 value 接力滚动（基准片 $13M→$118M→$125M 跟口播滚约 3s）。
- 反例：v3 countFrames=30（0.5s）+ 单位数滚动 = 视觉等于静态贴图（v3 旧单文件装配的 BigNumber 用例，原行号已随拆分 scenes/ 失效；组件真源 src/design/BigNumber.tsx）。

### 8. 持续动画转速下限：≥30°/s 且带不对称标记【sev3，查漏章】
- 旋转类图形（Flywheel、LOOP 虚线圈）转速 ≥30°/s（@30fps 即 ≥1°/帧），且必须带不对称标记（轮缘圆点/色差扇段/strokeDashoffset 流动），否则同构图形转了等于没转。
- ~~每章至少 1 个持续运动元素~~ **已废止（2026-07-25 实测）**：参考片全片零常驻微动，静止是常态。**唯一合法的「持续运动」是内容本身在动**——录屏/B-roll 素材、数字滚动过程、条形生长过程；这些是信息的一部分，不是装饰性动画。
- 章内 review 改问：「这 8 秒有没有新增量？」没有就加一件（rhythm §9），**不是给旧件加动画**。

### 9. 到位即静止：禁常驻微动（2026-07-25 逐帧实测改写，覆盖旧「Breathe 主角必包」）

- **元素进场完成后完全静止，不呼吸、不浮动、不漂移。** 实测参考片：大字进场后 125 帧内亮像素质心 x 波动 1.0px（std 0.42）、y 波动 0.21px（std 0.09）——纯阈值噪声；全帧差在动画结束后立刻降到 0.1-0.35 噪声底并保持。**全片零常驻微动。**
- ~~主角必包 `<Breathe>`~~ **已废止**：旧条来自「进场即死判不合格」的误诊——参考片不靠微动救静止，靠**下一次增量**（间隔 1-2s，rhythm §6）保持画面活性。加呼吸是「模仿错的三点」之一（另两点：spring 过冲、位移放大）。
- **存量片**：已挂 `<Breathe>` 的旧片不强制回改（改动面大、观感差异小）；**新片一律不挂**。组件保留在库中仅供特殊需求，不再是默认。
- 画面活性由**增量节奏**保证，不由持续动画保证——连续 8s 无任何增量仍判节奏空洞（rhythm §9），但补法是「加一件」不是「让旧件动起来」。

### 10. useEnter 默认入场规范（原 SKILL §4 搬入）
- 统一用 motion.ts 的 `useEnter`：滑入 MOTION.popInShift + 淡入，时长 MOTION.popInFrames（0.3s），`Easing.out(cubic)` 减速；透明度在前 70% 时间先到位（「先看见、再落定」）。
- **禁止用过阻尼 spring 压短时长**（会变成闪现，用户已否掉）。官方同向佐证（remotion-dev/skills timing）：**interpolate 优先于 spring**；方向规则「入场 Easing.out、退场 Easing.in」（带惯性来、带重力走）；干脆 UI 入场曲线参数 `Easing.bezier(0.16, 1, 0.3, 1)`（强 ease-out 无过冲，useEnter 手感升级候选）。
- **CSS transition / animation / Tailwind 动画类一律禁用**——官方 FORBIDDEN 级：渲染必坏（Remotion 逐帧截图，CSS 时间轴与帧无关）。
- 编排：同组元素同时入场传相同 enterAt；先后错峰用 MOTION.stagger 间隔；卡片类从左滑入（dir='left'），hero 大字从下滑入（dir='up'）。

### 11. 禁止项与强调预算（原 SKILL §4 搬入）
- 禁止：弹跳过冲（spring overshoot）、旋转入场、每元素都加动效声。
- 重锤级强调（大砸落 + 重 SFX 的组合拳）整条片 ≤ 2 处。
- **一段一个大动作（seg04 过审沉淀）**：戏剧性运动（坠落/顶替/爆开这类物理演出）每段最多一次，其余节拍全是持锤等口播——动作稀缺才有重量；两个大动作同段 = 互相稀释。物理动画曲线按「读得出物理」选：倾斜用线性（被顶即翻倒）、下坠用 ease-in（重力加速），全通道同曲线常读不出运动。

**三个近义强调概念作用域辨析（口径不同，别混）**：问「一段最多几个大动作」先分清是哪一个——

| 概念 | 量 | 作用域 | 真源 |
|---|---|---|---|
| 物理大动作（坠落/顶替/爆开演出） | ≤1 次 | **每段** | 本条（motion §11） |
| 整屏峰值拍（剪辑层切走人物的全帧插拍 2-4s） | ≥1 次 | **每章** | rhythm.md §2 |
| 重锤级强调（大砸落 + 重 SFX 组合拳） | ≤2 处 | **整片** | 本条 + audio.md 规则 1 |

三者可重叠（一次重锤通常就是某段的物理大动作、也常落在某章的峰值拍上），但计量单位分别是段/章/片，不能互相套用。

### 12. 装配级门控四件套：入场/让位/退场/清场各有专用包装器【sev4，2026-07-17 批量线沉淀】

useEnter/useExit/usePop 是底层 hook（在 `src/design/motion.ts`）；装配层实际高频用的是 **`src/koubo/scenes/shared.tsx` 四个包装器 `Enter/DimAfter/Exit/ClearOut`**（装配层共享门控件，全仓复用不逐片重写；直接套 children，勿在 Scene 里手搓 opacity）。按「解决什么问题」选：

- `<Enter at>`：**容器卡入场门控**。带底板的容器卡（darkPlate）若没有自己的 enterAt，会从章首就渲出空黑板（体检 s06 实锤）——凡有实底的容器卡必须包 `<Enter>` 或等效 enterAt 门控，否则空板提前露脸。**门控时点义务（0715-02 S06 打回补）**：容器卡 enterAt 必须绑定其首件内容的 enterAt——容器至多提前 ≤0.5s 立框，禁出「空容器等内容」；卡先出、内容数秒后才到 = 空板提前，与漏门控同罪打回（内容确需晚到时，容器与内容同拍进场或容器改跟内容拍；「空框先立」的决算场语法是刻意悬置例外，见 narrative §5）。
- `<DimAfter at to={0.4}>`：**让位门控——新片停用（2026-07-25，见 §4）**。参考片不做降级让位；本件保留仅供存量片与特殊需求。新片的做法是「旧件保持满亮到整组齐退」或「新件低亮度进场」。
- `<Exit at>`：**退场门控**。exitAt 起 useExit 淡出 + 轻降，`opacity≤0` 即 `return null` 卸载。章内旧元素让位、常规收尾用；每个收尾元素都要有（对应规则 1）。
- `<ClearOut at>`：**章尾清场门控**。线性 14 帧淡出 + 轻降 + scale 0.98，`t≥1` 卸载。刻意不用 useExit（其 ease-in 前段太平、清场起步不可辨，要立即可见）；章尾整组一次性清场、禁一帧硬切时用。

## 边界

- 节拍密度（每 20-60s 新包装点、相邻包装点类型不重复、主角时刻编排）→ rhythm 板块文件（remotion-assembly references/rhythm.md）。
- SFX 与动效的配声规则、音量链 → 音频板块文件。
- takeover 接管模式（只剩 A 级素材接管；「B 级压暗升格」已被用户否决，升格改靠字号提级 + 清场 + 红绿镜像框，见 layout §2）的层级与频次 → 版式/布局板块文件。

## 「丝滑感 / 高级感」五律（用户审美裁定沉淀，2026-07-23，铁律级）

> 来源：0722-01 终审用户对 S14 时间线的连续多轮反馈（「效果是插过去的」「不应该穿过圆圈」「不自然不连贯」「开头不该有下面的线」）。
> **这五条是「不高级」的归因表**：用户说「粗糙 / 不高级 / 像失误 / 不自然 / 不连贯 / 不丝滑」时，先逐条对号入座找出违反了哪条，再动手改——禁止凭感觉瞎调参数。

### 律 1：不预铺骨架（还没讲到的，不许提前显形）
未到达的结构一律不显示：灰色占位线、空槽、虚位、骨架线、待填的框，全部禁止在内容到达前出现。观众要看到内容**长出来**，而不是看到**预留的坑被填上**。
- 反面（0722-01 S14 实锤）：脊线画一条全长灰色底线做「轨道」，讲第一个节点时下方五段轨道已全部可见 → 用户直接指出「开头不应该有下面的那些线」。
- 正面：只渲染已生长到的部分；未到达段完全不挂载（不是 opacity 0，是不存在）。
- 自检：随便抽一帧问「这一帧上有没有东西是口播还没讲到的？」有 = 违规。

### 律 2：连贯优先于分离（避让不许把连续物切碎）
一条路径就是一条路径、一个整体就是一个整体。为了避让/防重叠而把连续物切成断续片段，**比原来的重叠问题更糟**——断续读作「碎」「不连贯」，是廉价感的第一来源。
- 避让的正确手法是**让位**：对方缩小、后退、降透明、让出空间；而不是**自断**。
- 反面（0722-01 S14 实锤）：为「线不穿圆」把整条脊线切成 5 段短线 + 留 4px 缝 → 用户反馈「非常不自然不连贯」，视觉读作虚线破折号。
- 判据：眯眼看，它还是「一条东西」吗？如果读成「几个碎块」＝违规。

### 律 3：边界相接，不穿不悬（缝隙 >2px 即读作断开）
元素与元素相接于**边缘**：不互相穿过（穿过＝没有边界意识，廉价），也不悬空留缝（留缝＝断开，见律 2）。
- 线与节点：线端**贴住**节点圆的外沿，视觉上连成「圆—线—圆—线」的链条。
- 缝隙经验值：0-1px 读作相接；≥3px 开始读作断开；4px+ 已明确是虚线感。
- 净空按**元素的最大状态**算（当拍节点会 scale 到 1.3 倍，按原始半径留空会被放大后的圆吃掉——0722-01 实锤）。

### 律 4：运动要有物理感（到达减速、落定回弹）
- 生长/位移：等速 = 廉价。必须缓起 + **强缓停**（`Easing.bezier(0.34,0,0.1,1)` 一类），到达目标时**减速停靠**，而不是等速撞上去。
- 分段行程：每段给**固定行程时长**（如 24 帧），间隔长就在起点待命，禁止把行程按时间间隔线性拉伸——那会让不同段速度不一，拐点突变，观感就是「一截一截插过去」。
- 落定：关键元素用 spring 轻回弹（`damping≈12, mass≈0.55, stiffness≈130`）收住，不要线性淡入了事。
- 反面（0722-01 S14 实锤）：`interpolate` 线性分段生长 → 用户「效果是插过去的」。

### 律 5：状态变化要有过程（禁瞬时整体突变）
颜色、尺寸、透明度、主次关系的改变都要有过渡帧，禁止某一帧整体切换。
- 反面（0722-01 S14 实锤）：整条脊线在某帧从蓝**瞬间**全变红 → 廉价感。
- 正面：颜色**绑定在空间位置**上（沿线 `linear-gradient` 蓝→红→绿），生长时自然穿过色相，已生长段保持它所处阶段的色；分段渲染时每段取**整条渐变上对应位置**的色（内层放满高渐变 + 负偏移对齐 + 外层裁切），而不是每段各自从头渐变。
- 主次切换（当拍提亮 / 旧元素退让）同理：用连续量 `dom = promote × (1 − demote)` 驱动 scale/opacity/gap，禁布尔硬切。

### 五律的元规则
- **律 1 与律 2 常同时被违反**：为了「防重叠」而切碎（违律 2），又为了「让人看懂结构」而预铺骨架（违律 1）。正确解是：不预铺 + 不切碎 + 靠让位避让。
- **改一条别踩另一条**：0722-01 修律 3（不穿圆）时踩了律 2（切碎）和律 1（露骨架），返工两轮。改动效前先把五条过一遍。
