# 色彩质感规则（texture）

依据：assembly/0715-01/深度对比报告.md「色彩与质感」8 条 + 修改单-04 对抗审查后勘误（裁决 1）+ 原 design-system SKILL §3 质感规范（已整体搬入本文件）。数值真源是 `src/design/tokens.ts`，本文件只写 token 名与比例关系。

## 适用时机

装配流程中三个时点必读：① 给某段选组件、定配色/表面变体时（尤其右区白板范围内的任何元素）；② 放置 Stamp / 大字 / ghost 装饰字之前；③ 每章装配完做同屏色彩自检时。渲染前自检也用本文件第 3、4 条复查。

## 规则

### 1. 表面自适应：元素配色跟随局部背景亮度（sev5，全板块第一优先）

- 暗底场景用半透暗玻璃（`SURFACE.darkPlate`，背景必须能透出）；亮面（白板/白墙/浅色素材）一律切换浅卡深字变体 `SURFACE.light`（含 bg/fg/stroke/shadow 四件套）。**禁止深色 HUD 卡直接压亮面**——黑 chip 压白板即「贴纸感」的头号来源。
- 装配层默认值：**右区白板范围内（约 x1150-1848）的组件默认 `surface='light'`**，左区保持暗玻璃。Chip / InfoCard / FlowChain 已支持 `surface` prop，用它，不要内联改色。

### 2. 亮面禁裸字实施细则（sev4，本条唯一真源在此，hub 铁律指向这里）

- **白字和 ghost 装饰字只准压暗底。**压亮面的文字必须二选一：反转为深色（用 `SURFACE.light` 的 fg，或语义色的深暗档），或垫 InfoScrim 半透深底再放白字。
- 半透白 ghost 大字（如 VALUATION 水印字）是暗底专属装饰，出现在白板上直接判不合格。
- 亮面上的彩色数字要复查对比度：黄/金字压白板偏低时改深金档或垫 scrim。
- **scrim 非默认挂（用户裁定 2026-07-24，0724-01 终审第一条）**：铺底背景本身是深色（暗墙/暗房）时**不挂 InfoScrim**、保持原片亮度——用户对「画面变暗」直接敏感。scrim 只在信息区背景亮到白字不可读时才用，且 `side` 必须跟信息区侧（错题 #36）；scaffold 生成的主组件已默认不挂（注释里写启用条件）。确需垫时用**羽化局部软渐变**（如左侧竖幅向右渐隐， segF 实测形态），禁整幅压暗。
- **无框浮动的前提条件（2026-07-25 立，0724-01 S03 翻车实锤）**：「图表/文字无框直压实拍」是语法，但它成立的**隐含前提是背景为大面积均匀暗墙**。落到背景复杂的片场（亮植物/白柱/彩色道具/高光区）会直接翻车——S03 实测：左区多层栈压棕榈亮部后主字近乎不可读，右区无框 rig 的节点与徽章飘到道具上像「黏在摆件上」。**判据链**：① 元素落区背景暗且均匀 → 直接无框；② 落区有亮部或杂色 → 垫**羽化局部软底**（只在该文字块/图形组下垫一层向外渐隐的暗渐变，肉眼近乎不可察，非整幅压暗、非硬边卡框）；③ 落区有强视觉道具（摆件/logo/高对比物体）→ 元素避开该区或整组给极淡暗玻璃底。**装配前用抽帧看落区**，别假设背景干净。堆叠层数越多，本条越致命——多层栈对背景纯净度的要求远高于单件。：蓝 #0A84FF=技术/结构/AI 方；金 #E6A737=价值/钱/与你有关；红 #F0413A=危机；绿=正确/成功；语义灰 ≈62% 亮度=贬义 ghost（「大路货」生即为灰）。**蓝金二元对立**是叙事底色（AI 抢 vs 人类值钱）；kicker 用蓝还是金＝告诉观众「这段与我有没有关系」；全片可走**色温叙事弧**金(机会)→红(危机)→白(行动)。彩色只上文字/图形本体——**无彩色描边框、无 glow 底板**；图表无框浮动（折线/横条/点阵直接浮在底纹或实拍暗部上，kicker+注文+数据本体三段式承载）。
- 验收标准：缩略图尺寸下读不清 = 不合格，以渲染帧为准不看源码。

### 3. Stamp 印章规格唯一线（裁决 1，覆盖报告一切旧口径）

- 尺寸：主行 fontSize **默认 48，章级重锤上限 64**，整体宽 **≤360px**。重锤感靠位置（锚定被判对象旁/贴卡角）+ SFX 实现，不靠尺寸。旧口径「78-110」「≤44」全部作废。
- 结构三件套：**图标 + 中文主行 + 加字距英文副行**（组件已支持 `icon` / `enSub` props；enSub letterSpacing 加宽、亮度比主行低一档）。单行裸字印章视为未完成。
- 底色：同色系色调化半透深底，背景必须能透出；**禁裸盖白板**——必须有深底，且贴卡角或锚定对象旁，不悬空盖在亮面中央。
- glow 只做提示不做光源：textShadow / boxShadow 均取轻量档（相对旧实现减半量级），双重强发光 = 霓虹贴纸。
- 同一判词禁止 chip 与 Stamp 同屏重复。判词该在哪个口播时点出现 → narrative.md。

### 4. 同屏高饱和语义色 ≤2 系（sev4）

- 同一画面高饱和色系最多 2 个；第三种语义色入场前，必须把已有彩色元素 dim 到 40% 或先行退场。
- 彩色只准出现在小面积：图标 tile、数字、描边、高亮词。大面积载体一律暗底灰白字或 `SURFACE.light` 浅卡。

### 5. 双语层级：中文永远比英文亮（sev3）

- 三层固定顺序：**彩色数字/大字 > 白色粗体中文 > 灰色加字距英文**。中文是给观众读的行，必须最亮（白 + zhHeavy/700 级粗度）；英文 kicker 保持灰 + 加字距。
- 反例：BigNumber 中文副行曾用 greyDim 比英文还暗，已修，装配新组件时不得再犯。

### 6. 卡片内图标一律装「语义色 tile」（sev3）

- 卡内图标装进圆角方 tile：语义色细描边（约 1.5px）+ 同色约 12% 透明底 + 语义色线性图标。禁止裸图标、禁止纯色实心块。
- 卡内文字逐行语义配色：日期/金额用语义色、中文主行白色、负面行红系。

### 7. 同一图元内底色规格必须一致（sev3）

- 一个图形件（如 LOOP 环）的中心与所有节点用同一底色规格（按第 1 条 surface 变体走），角色差异只靠描边色和文字色表达。禁止中心浅底、节点黑底两套逻辑并存。

### 8. 图形类组件默认线框风（sev2）

- 飞轮/环/曲线类：描边 ≤4px、辐条更细、节点用小圆点、能透出背景；禁止大面积高饱和实心填充与实心大圆块。

### 9. 质感基线（原 SKILL §3 全文搬入，hub 只留指针）

- **禁止纯平色块**：语义色面积块（矩阵方块、徽章底）一律用同色系「果冻块」渐变 `linear-gradient(160deg, 亮 0%, 暗 100%)` + `inset` 高光/暗边（见 MatrixIcon 的 CELL_GRADIENT）。
- **语义色元素带同色 glow**：矩阵/印章/徽章卡加 `drop-shadow(0 0 28px 语义色40%)` 或 boxShadow 外发光；大字标题加轻微白光 textShadow。（Stamp 的 glow 上限以第 3 条唯一线为准，比这条基线更严。）
- **背景禁止纯平黑**：Bg 用径向渐变（左上偏亮）+ 中心透明四角压暗的 vignette 叠层，制造画面层次。
- **品牌 logo 一律用真图**：`@lobehub/icons-static-png` 全套 AI 品牌 logo 已装（存 `public/assets/logos/`）——`*-color.png` 彩色通用，`dark/` 白 logo 适深底（窗口标题栏），`light/` 黑 logo 适白底方块。禁止拿 lucide 线条图标冒充品牌 logo（用户已否掉）。
