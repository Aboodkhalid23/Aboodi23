# مصادر المواد

القائمة الكاملة (38+ مصدر، رخصة كل واحد، ومربوط لو يدوي): `editor/sources/CATALOG.md` (تتولد من `editor/sources/catalog.json`).

## القواعد
1. **الرخصة أول شي:** القناة بيها أرباح. مسموح: CC0، ملك عام (PD)، CC BY (ويه ذكر المصدر بالـ credits)، رخص المواقع الحرة (Pexels، Pixabay، Mixkit). **ممنوع:** NC (غير تجاري)، ND، رخصة BBC، الأرشيف المدفوع إلا إذا صاحب القناة اشترى.
2. **الحقيقي أول، والذكاء الاصطناعي آخر شي** (قرار صاحب القناة). الصوت ببلاش.
3. كل مادة تنكتب بالـ credits تلقائياً (المونتير يسويها). المادة اليدوية: ضيف سطرها بـ `edit/credits.txt` بنفسك.

## شنو منين (المونتير يدوّر لحاله بالمربوط)
| أحتاج | المصدر | شلون بالخطة |
|---|---|---|
| شخص، شركة، مكان، حدث | ويكيميديا، Openverse، Europeana، مكتبة الكونگرس | `image` ويه `query` |
| تاريخ ولوحات وصور قديمة | مكتبة الكونگرس، متاحف شيكاغو وكليفلاند، Europeana، Wellcome | `"source": "archive"` (أو سنة بالكلمات) |
| **صفحة جريدة قديمة حقيقية** | Chronicling America | `"source": "newspaper"` |
| مشهد حديث عام (زحمة، مكاتب) | Pexels، Pixabay (مفتاح مجاني) | `"source": "stock"` |
| فيديو قديم أو جرائد سينما | أرشيف الإنترنت، ناسا، ويكيميديا | `footage` |
| موسيقى | جامندو (عبر Openverse) | `music-free` تلقائي |
| مؤثر صوتي | Freesound CC0، Kenney | أي اسم بـ `sfx` |
| **إيموجي متحرك** 🔥😱💰 | Google Noto (Lottie) | ملصق `{"type": "emoji", "text": "🔥"}` |
| أيقونة ملونة | Iconify (مجموعات حرة بس) | ملصق `{"type": "icon", "text": "fluent-emoji-flat:money-bag"}` |
| صورة أو فيديو ما موجود بالواقع | هيگزفيلد (رصيد صاحب القناة) | `ai_image`، `ai_video`، `avatar` |

## يدوي (بدون ربط): استخدمها لما المربوط ما يكفي
Mixkit وCoverr وVidevo (فيديو حديث)، مكتبة يوتيوب الصوتية وIncompetech وFree Music Archive (موسيقى)، Sonniss (حزم مؤثرات)، LottieFiles وOpen Peeps وunDraw (رسومات وأنميشن)، Poly Haven (ملامس CC0)، Our World in Data والبنك الدولي (أرقام للرسوم البيانية).

## الصيانة
- `python -m editor.pipeline.catalog --check`: يسأل كل المصادر ويحدّث الحالة والقائمة. الفحص التلقائي ببداية كل جلسة (`doctor`) يسأل المربوطة.
- مصدر واقف: البحث يتخطاه لحاله. إذا بقى واقف: صلّح المحوّل بـ `editor/pipeline/sources.py` أو بدّل المصدر.
- **إضافة مصدر جديد:** دالة بـ `sources.py` ترجع `Found` (فلتر الرخصة داخلها)، وحطها بـ `IMAGE_ORDER` أو `VIDEO_ORDER`، واختبار بجلسة وهمية بـ `editor/tests/test_sources.py`، وسطر بـ `catalog.json`، وبعدها `catalog --check`.
