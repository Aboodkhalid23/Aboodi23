# MG 段落评分卡（独立质检 agent 专用，2026-07-16 采纳清单 B1）

> 用途：质检 agent（mg-judge）对每个渲好的段落打分，**送用户终审前必过**。原则来自 Anthropic harness 工程实践：干活的不给自己打分；评分维度必须可编码，不许模糊审美。打分要刻薄——「大概还行」= 不合格。

## 使用方式

输入：段视频抽帧（2fps 网格 + 关键拍单帧）、该段方案文档（beat 表/占位表）、QC 探针报告（qc-report.json）。
输出：四维各 0-10 分 + 违规清单（带帧号）+ 一句话裁决（送审 / 打回）。**任一维 <7 或存在 FAIL 级违规 = 打回**。

## 生产模式：批量扫批（提速方案两路，对应研发模式的三道闸）

批量生产阶段 mg-judge 按「扫批」跑，不逐段重走全套：

- **每段只读四样**：该段自核抽帧（2fps 网格 + 关键拍单帧）+ QC 探针报告（qc-report.json）+ 方案红线清单（beat 表/占位表里已固化的编排红线）+ **该段 SRT 切片**（维度 2 语义对齐抽查的比对轴——必须对 SRT 原文核，不得只对 beat 表核；beat 表漏排正是 S04 盲区成因）。**不重读参考片抽帧**——参考编排逻辑已落进方案红线，扫批核的是「有没有踩红线」而非重新比对参考帧。
- **判据不降**：四维打分与「任一维 <7 或 FAIL 级违规 = 打回」照旧；砍掉的只是重复读取，不是质量线。
- **送审汇入页面确认制**：扫批送审的段进批量审核页（视频 + beat 表 + QC + 对比图），按 §2.5.1 阶段 5 的批量审核页节奏攒多段一次交用户批量终审；用户终审是最终闸，扫批不替代。
- **弹性升级（量化门槛）**：首次被扫批打回 = 定点修 + 只重验该段（仍在生产模式），不升级；**同一段被扫批打回 ≥2 次、或该段任一次用户终审返工**（说明该段模式新、超出方案红线覆盖）才把该段单独升回研发模式全维——重读参考片抽帧做举一反三对照，不搞一刀切。
- **静帧盲区照旧归用户**：扫批同样看不出动效手感，连贯性一律标「需用户动态终审」。

## 四维评分

### 1. 版式章法（layout.md/specs.md 可查条款）
- [ ] QC 探针报告零违规（重叠/字幕净空/最小字号）——FAIL 级
- [ ] 一屏一个主导层：唯一最大字 ≥ 同屏最小字 3 倍；非主区 ≤2 个芯片级小元素
- [ ] 左区有 ≥2.5:1 视觉锚点；等宽等距连堆 ≤3
- [ ] 元素规格对 specs.md（卡宽/字号/印章 ≤360/接管卡 ≥1100）
- [ ] 白板安全框内无骑线；同组元素同底

### 2. 节拍对位（rhythm.md/§2.5 词级对齐）
- [ ] 主视觉入场 = 概念名词 SRT 首现 ±0.5s（对照 beat 表逐项核）——FAIL 级偏 >1s
- [ ] **语义对齐抽查（2026-07-20 补，S04 盲区实锤）**：从该段 SRT 抽 3-5 个关键实体（人名/数字/判词），逐个核「说到 X 的那帧，画面里有 X 的对应呈现且清晰可读」——说了没出、或被前拍残留元素挤到看不清，都算未对齐；任一关键实体未对齐 = 本维 ≤6（0715-02 S04「连马斯克都认同」无画面呈现，四维 8888 全过却被用户终审打回，即此盲区）
- [ ] 换拍间隔 3-5s；连续 8s 无画面变化 = 违规
- [ ] 元素常驻 ≤2 beat；新主角进场旧主角退场或 dim
- [ ] 章尾清场 + 空屏呼吸；无一帧硬切消失

### 3. 工艺质感（typography.md/texture.md/motion.md）
- [ ] 亮面无裸字；语义色 ≤2 系/屏；chip 带图标
- [ ] 双语层级：白色粗体中文 > 灰色英文；混排有空格；无错字
- [ ] 动效三档词汇用对（大卡显影/chip 滑入/印章砸落）；旋转件带不对称标记且 ≥30°/s
- [ ] 每章 ≥1 个持续运动元素；无「进场即死」的 3 秒静止主角

### 4. 反 AI 味 / 原创贴合（narrative.md + 参考片）
- [ ] 不是「元素罗列」：图形载体跟口播演变形（占位→变化→反转类结构），有因果感
- [ ] kicker 文案不 overclaim（不说口播没说的）；判词 chip 与 Stamp 不重复
- [ ] 与参考片同拍对比不缩水（尺寸/密度/胆量）；但禁止照抄到失去语义（举一反三检查：换个产品名这套编排还成立吗）

## 裁决输出格式

```
维度分: 版式 X/10 | 节拍 X/10 | 工艺 X/10 | 原创 X/10
违规: [帧号] 条款 → 具体描述（每条可定位、可修）
裁决: 送审 / 打回（打回必须给修法，不许只说不好）
```
