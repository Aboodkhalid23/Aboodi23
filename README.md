# 👋 ابدأ من هنا

هذا الريبو هو "عدّة الشغل" مال Claude. بيه **20 سكيل** تخليه أشطر بالتطوير والبحث وإدارة الشغل، وتتحدث وحدها.

## شنو يعني "سكيل"؟
تخيّلها **وصفة طبخ**: ملف تعليمات يعلّم Claude شلون يسوي شغلة معيّنة بأحسن طريقة.
ما تحتاج تحفظها أو تشغّلها بنفسك. Claude يختار الوصفة المناسبة وحده حسب طلبك.

## شلون تستخدمهن؟
**بس احچي طبيعي.** أمثلة تگدر تنسخها:

| تريد | اكتب لـ Claude |
|---|---|
| مساعد لشغلك | «ساعدني أرتب خطة شغل لهذا الشهر» |
| تبحث بموضوع | «سوّيلي بحث عميق عن سوق القهوة بالعراق» |
| تسوي موقع | «سوّيلي صفحة بسيطة تعرّف بمشروعي» |
| تصلّح مشكلة | «هذا الكود يطلع خطأ، صلّحه» |
| تتعلم شي | «علّمني شنو يعني Git من الصفر» |
| جواب مختصر | «/caveman» وبعدها اسأل |

وإذا تريد سكيل معيّن، اكتب `/` واسمه، مثلاً `/ceo-assistant`.

## شنو موجود بالريبو؟
| الملف | شنو هو |
|---|---|
| `README.md` | هذي الصفحة |
| `SKILLS_GUIDE.md` | شرح مفصّل لكل السكيلزات، وشنو تفيدك |
| `CLAUDE.md` | تعليمات لـ Claude: إنك مبتدئ، ويحچي وياك عراقي، ويشتغل عنك |
| `skills.manifest` | قائمة السكيلزات المثبتة |
| `scripts/update-skills.sh` | السكربت الي يثبّت ويحدّث السكيلزات |
| `.claude/` | مكان السكيلزات والإعدادات. لا تلعب بيه بيدك، خلي Claude يعدّله |

## ⚠️ مهم
- **الريبو عام (public):** أي أحد يگدر يشوفه. لا تكتب بيه باسوردات أو معلومات خاصة بشغلك.
  إذا تريد تخليه خاص: GitHub ← الريبو ← **Settings** ← آخر الصفحة **Change visibility** ← **Make private**.
- أي شي ما تفتهمه، اسأل Claude: «اشرحلي شنو يعني ...».
