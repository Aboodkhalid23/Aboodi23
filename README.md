# 👋 ابدأ من هنا

هذا الريبو هو "عدّة الشغل" مال Claude. بيه **29 سكيل** تخليه أشطر بصناعة المحتوى والتطوير والبحث وإدارة الشغل، وتتحدث وحدها، وبيه **فريق كتابة كامل** لقناتك.

## شنو يعني "سكيل"؟
تخيّلها **وصفة طبخ**: ملف تعليمات يعلّم Claude شلون يسوي شغلة معيّنة بأحسن طريقة.
ما تحتاج تحفظها أو تشغّلها بنفسك. Claude يختار الوصفة المناسبة وحده حسب طلبك.

## 🎬 استوديو المحتوى (فريقك)
عندك فريق من 6 موظفين يشتغلون كأنهم شركة، وانت الوجه الإعلامي:

| الموظف | شغله |
|---|---|
| 🔭 مكتشف المواضيع | يدور على الترند وقصص الشركات والأسئلة الغريبة، ويرتبها حسب القوة |
| 🔎 الباحث | بحث جديد وعميق: قصص وتواريخ وأرقام ومصادر |
| ✍️ الكاتب | سكربت 2800+ كلمة بلهجة عراقية، بهوك قوي وتشويق لآخر الحلقة |
| 🧐 المدقق | يتأكد من كل اسم وتاريخ ورقم، ويصحح الغلط |
| 🗣️ محرر اللهجة | يشيل الفصحى وكلام الذكاء الاصطناعي، ويضبط الإيقاع |
| 📦 مسؤول العنوان والسيو | العناوين، وفكرة الصورة المصغرة، والوصف والتاگات |

**شلون تشغّله:** اكتب لـ Claude:
- «اقترحلي مواضيع» ← يجيبلك أفكار وانت تختار.
- «سوّيلي سكربت عن ...» ← الفريق كله يشتغل ويسلمك السكربت جاهز.

**وين تلگى النتيجة:** بمجلد `episodes/` كل حلقة إلها مجلد، والسكربت النهائي بملف `04-script.md`.

## شلون تستخدمهن؟
**بس احچي طبيعي.** أمثلة تگدر تنسخها:

| تريد | اكتب لـ Claude |
|---|---|
| مساعد لشغلك | «ساعدني أرتب خطة شغل لهذا الشهر» |
| تبحث بموضوع | «سوّيلي بحث عميق عن سوق القهوة بالعراق» |
| تسوي موقع | «سوّيلي صفحة بسيطة تعرّف بمشروعي» |
| تصلّح مشكلة | «هذا الكود يطلع خطأ، صلّحه» |
| تتعلم شي | «علّمني شنو يعني Git من الصفر» |
| جواب مختصر | «/caveman» وبعدها اسأل |

وإذا تريد سكيل معيّن، اكتب `/` واسمه، مثلاً `/ceo-assistant`.
