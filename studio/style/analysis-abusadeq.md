# تشريح صنعة أبو الصادق (آخر 10 حلقات طويلة، 28-34 دقيقة، 2.2 إلى 3.8 مليون مشاهدة)
> دراسة مو قالب. القناة: UCLB2b6r4jfV4vs6Hvv0YO2g.
- **الهيكل الثابت:** 0-3 د: افتتاح بارد (تاريخ ومكان وتفصيلة حسية) ← 2-3.5: 5-6 أسئلة بنَفَس واحد ← جملة وعد ← وعد منفعة ("بعد الحلقة راح تعرف...") ← "البداية" ويرجع للجذور بتسلسل زمني ← فصول 2-4 د كل فصل ينتهي بسؤال أو انقلاب ← آخر 3 د: "الأهم من القصة" والدرس ← سؤال تعليقات.
- **أول 60 ثانية:** جملة أولى = تاريخ + مكان + شي يتحرك (مو فكرة). بعد 20-30 ثانية تفصيلة "ما تركب" (ما انكسر باب، ما انسرق شي). يخبي: الفاعل أو السبب أو المصير.
- **كدّس الأسئلة قبل الوعد:** 4-6 أسئلة بنفس الإيقاع، أكبرها آخرها.
- **كل فصل "كان مفروض... بس":** معلومة ثم يكسرها.
- **ازرع واحصد:** "احفظ هالاسم" قبل الدقيقة 10 وترجع بالآخر بمعنى مختلف.
- **المشاهد محقق:** معلومة صغيرة غير مفهومة "تذكرها" ثم تربط بشي ثاني.
- **إيقاع:** كل 2-3 د رقم أو سؤال أو "يعني بالعراقي"، وكل 5-6 د إعادة جذب ("جيب استكان الچاي").
- **"هذا مو كلامي" قبل رقم ثقيل** (تشويق وأمانة سوة).
- **النهاية بتحويل:** القصة ← "الأهم من القصة" ← ربط بالبداية ← سؤال ← اقتراح حلقة.
- **قوالب هوك:** (1) المشهد ثم الكسر. (2) الرقم الي يكبر ("بالبداية X، بعد دقيقتين Y... والكل يعرف مين سواها، ومحد گدر يسوي شي، ليش؟"). (3) الجواب گدامك ("لو سألتك X جوابك Y، وهذا الغلط").
- **فرق عن عمر:** أبو الصادق قصة وتسلسل زمني ونَفَس طويل، عمر إثارة وتحليل وصدمة أسرع.
