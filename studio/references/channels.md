# القنوات المرجعية (نستلهم التقنية، ما ننسخ)

| القناة | التقنية الي ناخذها | متى نستخدمها |
|---|---|---|
| **عمر أبو الروب** | سؤال محد يسأله + جواب يغير نظرتك. المقدّم بالكادر أغلب الوقت، والأوراق والصور تطلع يمّه. | الأسئلة الغريبة، ووثائقي قصير مكثف |
| **الدحيح** | تبسيط المعقد بتشبيه يومي + نكتة تكسر الجدية كل دقيقتين تقريباً. يفكك الترند لقطع صغيرة. | علوم، اقتصاد، ترند معقد |
| **أبو الصادق** | سرد قصصي عراقي أصيل: "خلي أحچيلك…"، شخصيات، توتر، ونهاية تلف على البداية. | قصص شركات، صعود وسقوط |
| **قرية العجائب** | غرابة وإيقاع سريع: معلومة صادمة كل 20–30 ثانية. | ترندات، قوائم، أشياء غريبة |
| **فوكس** | فكرة وحدة واضحة، والصورة تشرح: ورق، أرشيف، خرائط، أرقام تنرسم. السؤال بالأول والجواب بالآخر. | أي موضوع بيه أرقام أو تاريخ أو مكان |
| **جوني هاريس** | المقدّم يحقق قدامك: يمشي بالخريطة، يأشر على الوثيقة، "خلي أوريك". | السياسة، الجغرافيا، التحقيقات |
| **ماگنيتس ميديا** | قصة الملياردير/الشركة كأنها فيلم: صعود ← قرار مصيري ← سقوط أو انتصار. | قصص الشركات والأثرياء |

## الدرس المشترك
1. **وعد واحد** بالعنوان، والحلقة كلها توفي بيه.
2. **لغز** ينفتح بالهوك وينسد بالنهاية.
3. **كل 60–90 ثانية** شي جديد: معلومة، انقلاب، سؤال.
4. **المقدّم شخص**، مو صوت: رأيه، دهشته، نكتته.
