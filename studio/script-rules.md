# دستور كتابة السكربت

هذا الملف هو المرجع الأساسي للكاتب ومحرر اللهجة والمدقق. مأخوذ من سكيل صاحب القناة `youtube-documentary-scripts-ar`، ومضاف عليه هيكل الاحتفاظ من سكيل `long-form-youtube`.

## 1. قوانين ما تنكسر
1. **الطول:** 2800 كلمة عربية كحد أدنى. عدّها فعلياً:
   `python3 -c "import sys;print(len(open(sys.argv[1],encoding='utf-8').read().split()))" FILE`
   إذا ناقص، ضيف قصص وتفاصيل حقيقية موثقة (من ملف البحث)، مو حشو أو تكرار.
2. **بحث جديد:** كل معلومة لازم تجي من `01-research.md` لهاي الحلقة. ممنوع معلومات من الذاكرة أو من حلقات قديمة.
3. **الحداثة:** نص القصص على الأقل أحداث من آخر سنة-سنتين من تاريخ اليوم. القديم خلفية بس.
4. **ممنوع صياغات تربك التوقيت** مثل "لازم نرجع أربع سنين للوراء". اذكر السنة صريحة ("سنة 2020") واربطها فوراً بالحاضر.
5. **لهجة عراقية 100%** (القسم 4).
6. **ممنوع وصف المشهد البارد:** مثل "قاعة عزاء. صمت ثقيل." كل جملة محكية وتخاطب المشاهد، مو موصوفة.

## 2. الهيكل (مبني على long-form-youtube)
| القسم | الوقت التقريبي | الشغل |
|---|---|---|
| الهوك | أول 30 ثانية (~70 كلمة) | يأكد وعد العنوان، ويفتح لغز ما ينسد إلا بالنهاية |
| التمهيد | ~1-2 دقيقة | شنو على المحك وليش يهمك انت |
| الفصول | 4-6 فصول | كل فصل قصة صغيرة: بداية، توتر، حل، ويفتح اللي بعده قبل ما يسد نفسه |
| نقطة الهبوط | 40-60% من الحلقة | أكبر مفاجأة أو تصعيد حتى ما يطلع المشاهد |
| الخاتمة | آخر دقيقة | يسد اللغز الأول، ويرجع لجملة أو رقم من الهوك |
| الدعوة | آخر 15 ثانية | طلب واحد بس + تشويق للحلقة الجاية |

- **حلقة مفتوحة كل 60-90 ثانية** (تقريباً كل 150-200 كلمة): "بس هذا مو أغرب شي، الأغرب راح أگولك عليه بعدين".
- **تلخيص بالنص (recap)** إذا الحلقة طويلة.
- **الترتيب الزمني:** ارسم الخط الزمني قبل الكتابة، وكل انتقال بين قصتين يوضح الفرق الزمني ("وبعدها بسنتين..."، "وهسه بـ2026...").

## 3. الهوك
- رقم أو حقيقة صادمة ومحددة جداً + شي يمس المشاهد نفسه (فلوسه، صحته، حياته، فهمه)، بأول 2-3 جمل.
- خاص 100% بهذا الموضوع. هوك يصلح لأي فيديو = مرفوض.
- **الاختبار:** "لو قريت هالجملة لوحدها، توقفني عن السكرول؟" إذا لا، أعد كتابتها.
- **الأنواع:** سؤال / رقم / تحدي / تناقض / نتيجة أولاً. لازم يختلف عن آخر 3 حلقات بـ `episodes/log.md`.

## 4. اللهجة العراقية
- **قاموس أساسي:** شنو، هسه، اكو/ماكو، شلون، جان، تره، گال، عدنه، هواي، زين/خوش، ليش، وين، شگد، يمعود، حيل، بعد، لعد.
- **بدائل الفصحى:**

| لا تكتب | اكتب |
|---|---|
| يتوجب / ينبغي | لازم |
| آنذاك | بهذاك الوكت |
| جراء | بسبب |
| وفقاً لـ | حسب |
| حيال | بخصوص |
| غالباً ما | بأغلب الأوقات |
| المفارقة | الشي الغريب |
| استقصائي | تحقيقي / حفروا وطلعوا |
| يخيّم | مسيطر |
| إذ | (احذفها) أو "وقتها" |
| يُذكر أن | (احذفها) |
| لكن | بس |
| الآن | هسه |
| كثيراً | هواي |
| ماذا / لماذا / كيف | شنو / ليش / شلون |

- **المصطلحات التقنية وأسماء العلم** تبقى مثل ما هي، وبعدها جملة محكية تشرحها.

## 5. كليشيهات الذكاء الاصطناعي (ممنوعة)
"في عالم مليء بـ..."، "دعونا نغوص"، "رحلة مثيرة"، "لا يخفى على أحد"، "في الختام"، "ليس فقط... بل..." بشكل متكرر، "مو بس X، هاي Y" أكثر من مرة وحدة، ثلاثيات متكررة (سريع، قوي، ذكي)، أسئلة بلاغية ورا بعض بدون جواب، "وهنا تكمن المشكلة"، "يطرح تساؤلات عديدة"، مبالغات عامة بدون رقم.

## 6. الإيقاع
- **موجة طول الجملة:** 2-3 كلمات للصدمة، 5-7 للسرد، 8-10 للتنفس. لا تكرر نفس الطول أكثر من 3-4 جمل ورا بعض.
- **تقنيات:** Pattern Break، يقين كاذب ثم انقلاب، سلّم تصعيد، الكلمة القوية بآخر الجملة، تزرع شي وتحصده بعدين، "تخيّل انت..."، تناقض حاد.
- **STEPPS:** قيمة اجتماعية، محفّز، عاطفة عالية الإثارة، علني، فائدة عملية، قصة.

## 7. شكل التسليم
- **ملف المسودة (`02-draft.md`) والنهائي (`04-script.md`):** نص واحد متواصل، بدون عناوين أو مشاهد أو ملاحظات إنتاج.
- **الأرقام** بالأرقام (2026، 3 مليار).
- **الادعاءات عن أشخاص أو شركات:** تنسب لمصدرها ("حسب رويترز..."، "حسب المحكمة..."). ما نتهم أحد بشي ما ثبت.
