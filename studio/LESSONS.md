# دروس الاستوديو (تكبر ويه كل حلقة)

كل سطر: **شنو صار ← القاعدة**. الكاتب والمدير الإبداعي ومحرر اللهجة يقرونه قبل كل حلقة.

## ذوق صاحب القناة
- ما يريد مواضيع عراقية، ولا "ربط بالعراق" ← عالمي، والربط بحياة المشاهد (فلوسه، شغله، فضوله).
- ما يفهم إنگليزي ← كل ملف يوصله عربي، والأسماء الأجنبية بحروف عربية بالسكربت حتى يقراها بسهولة.
- يحب ستايل فوكس، ويبقى بالكادر والأوراق يمّه ← السكربت يذكر المصدر بالاسم ("نشرت رويترز…"، "بتقرير البنك الدولي…") حتى تصير ورقة يمّه.
- عنده مصمم للصور المصغرة ← نقترح فكرة بس.

## الكتابة
- سكربت إيفرغراند (أول حلقة): 4321 كلمة بس 6 حلقات مفتوحة بس ← حلقة مفتوحة كل 150–200 كلمة، والمدقق الآلي يعدها.
- الرقم الكبير لحاله ما يحس بيه المشاهد ← قرّبه: "يعني كل واحد بالصين…".
