# قاموس الكلمات الصعبة (صاحب القناة يتعثر بيها أو ما يفهمها)

> صاحب القناة عنده صعوبة بالنطق. أي كلمة يگول عليها صعبة تنضاف هنا، والفاحص الآلي يأشّرها بأي سكربت.
> الشكل: كل سطر بالجدول = الكلمة الصعبة | البديل السهل.
> القواعد العامة بـ`studio/style/method.md` القسم 2ب.

| الصعبة | السهلة |
|---|---|
| محكوم عليه | چانوا راح... |
| ينفك | ينشال |
| يفكونه | يشيلونه |
| وقّعوا | كتبوا |
| يسمونه بيها | گالوا عليه |
| يتغدى | ياكل غدا |
| هوائي | مكان للراديو |
| البث بدون أسلاك | الراديو |
| مدّدوا | خلّوه |
| يلقط | يسمع |
| فضحت | كشفت |
| انقبض عليها | مسكوها |
| فلهذا | لهذا |
| موباسان | كاتب مشهور |
| مستعار | ثاني (باسم ثاني) |
| كود | أسرار، أو اشرح شنو هو |
| اللابتوب | الكمبيوتر |
