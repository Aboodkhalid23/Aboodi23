# URU (كان اسمه المونتير) للماك

تطبيق ماك خاص بصاحب القناة: استوديو مونتاج بست خطوات (الجمل، الصوت، الكابشن، الخطة، البناء، الملاحظات)، وتايم لاين، وألوان، ومساعد (كلود)، على حاسبته.
الشعار: `app/mac/icon.svg` (مرسوم بالكود: الاسم، وتحته موجة صوت ومؤشر التايم لاين الأصفر).

## شلون ينبني
- جهاز ماك بالسحابة (`.github/workflows/mac-app.yml`) يبنيه لحاله ويه كل تغيير بـ `app/` أو `editor/app/`، ويحطه هنا:
  `https://github.com/aboodkhalid23/aboodi23/releases/download/mac-app/URU.dmg` (و`Montier.dmg` نفس الملف، للرابط الأول)
- نفس الجهاز يجرب التنصيب الكامل والتجهيز على فيديو صغير، فإذا رابط تنزيل خرب يبين هناك.
- **التحديث من داخل التطبيق:** الإعدادات ← «حدّث»: يجيب آخر كود، وبعدها يبدّل التطبيق نفسه (`setup.sh --app`) إذا اكو نسخة أحدث بـ `app-version.txt`، ويرجع يفتحه. التطبيق القديم (المونتير) يتبدّل لحاله بـ URU أول مرة.
- التطبيق مو موقّع من آبل (ببلاش): أول مرة ينفتح من الإعدادات ← الخصوصية والأمان ← "افتح على أي حال".

## الأجزاء
| الملف | شنو يسوي |
|---|---|
| `app/mac/App.swift` | النافذة: أول مرة تنصّب، وبعدها تشغّل المحرك وتعرضه |
| `app/mac/setup.html` | شاشة التنصيب |
| `app/setup.sh` | التنصيب والتحديث: بايثون، برنامج الفيديو، أدوات الرسم، كلود، موديل التفريغ. بدون صلاحيات مدير |
| `editor/app/server.py` | المحرك: الحلقات، الخطوات (تجهيز، خطة كلود، النسخة الكاملة، غرفة المونتاج، الطلبات) |
| `editor/app/ui/index.html` | استوديو المونتاج (الواجهة القديمة: `simple.html`) |
| `editor/app/studio.py` | بيانات كل خطوة: الجمل وسبب القص، الكابشن وشك التفريغ، بطاقات الخطة، التايم لاين، صور الألوان |
| `editor/app/ui/room-shim.js` | يخلي غرفة المونتاج تشتغل بالتطبيق (الحفظ والطلبات والصوت بمجلد الحلقة) |

## على حاسبته
- الأدوات والكود: `~/Library/Application Support/Montier` (والسجلات بـ `logs/`).
- الحلقات: `~/Movies/المونتير` (التحديث ما يمسها).
- خطة المونتير: `claude -p` بحسابه (بدون صرف رصيد ذكاء اصطناعي مدفوع)، والأدوات المسموحة بس الي يحتاجها المونتير.

## اختبار هنا (لينكس)
`MONTIER_HOME=<مجلد> MONTIER_CODE_SRC=$PWD MONTIER_SKIP_CLAUDE=1 MONTIER_SKIP_MODEL=1 bash app/setup.sh`، و`python -m editor.app.server`، و`pytest editor/tests/test_app.py`.
