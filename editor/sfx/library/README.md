- كل الملفات هنا من **Kenney** (kenney.nl): رخصة **CC0** (ملك عام). مسموح تستخدمها تجارياً بيوتيوب، وبدون ذكر المصدر.

- الأصوات الي ما إلها مجلد هنا (`whoosh`، `riser`) تتولد بالكود (`editor/pipeline/sfx.py`)، وما إلها حقوق.
- لإضافة صوت: حطه بمجلد اسمه، والرخصة لازم CC0 أو صنعناه إحنا.
