# مكتبة الستايلات

كل ستايل ملف `.md` بهذا الفولدر. فوگ الملف (بين `---`) إعدادات يقراها الكود، وتحتها ملاحظات حرة بالعربي يقراها Claude.

| الحقل | شنو يعني |
|---|---|
| `name` | اسم الستايل بالإنگليزي، نفس اسم الملف |
| `summary` | سطر أو سطرين: شكل الستايل وجوّه. Claude يختار الستايل من هذا السطر |
| `fits` | أنواع الحلقات الي يناسبها |
| `palette` | ثلاث ألوان: `paper` (الخلفية)، `ink` (الكتابة)، `accent` (التأكيد) |
| `fonts` | `title` و`body`: خطوط عربية (لازم تكون منصبة بـ Remotion) |
| `texture` | `paper` أو `grain` أو `clean` |
| `image_treatment` | معالجة الصور: `paper_cutout` أو `ken_burns` أو `film_grain` |
| `transition` | نوع الانتقال (`slide`، `cut`، `fade`) |
| `beat_seconds` | مدة الـ beat المفضلة بالجسم (بين 4 و 6) |
| `music_mood` | جو الموسيقى (بالإنگليزي، يستخدم للتوليد بالجزء 2) |
| `sfx` | الأصوات الي يستخدمها |
| `ai_suffix` | جملة تنضاف لكل وصف صورة ذكاء اصطناعي حتى تطلع بنفس الستايل |

## إضافة ستايل جديد
1. انسخ `vox.md` باسم جديد وغيّر القيم.
2. إذا يحتاج گرافيكس بشكل جديد، أضف قالب بـ `editor/remotion/src/graphics/`.
3. شغّل `cd editor && python -m pytest -q`.
