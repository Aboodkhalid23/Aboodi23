# القطع المشتركة (كل الستايلات تستخدمها)

الستايل يحدد **الألوان والخطوط والجو**. القطع هنا تشتغل بأي ستايل وتاخذ ألوانه لحالها، فكل قطعة جديدة تقوّي كل الستايلات القديمة.

## المقدّم بالكادر
| القطعة | بالخطة | متى |
|---|---|---|
| أوراق يمّه | `face_paper` (`newspaper`، `document`، `photo`، `quote`، `number`، `page`) | خبر، وثيقة، تصريح، رقم: الأساس |
| ورقة تنقلب مثل الكتاب | `"enter": "turn"` (تلقائي للورقة الثانية والرابعة) | ورقة تكمّل الي قبلها |
| ورقة تنزل مثل الختم | `"enter": "drop"` | رقم أو حكم صادم |
| لوحة تحقيق | `"link": true` بكل ورقة | أدلة تترابط (ستايل `investigation`) |
| الورقة من ورا كتفه | `"treatment": "behind"` | أهم 2–4 أخبار (تصوير عرضي) |
| مكتب ورق | `"treatment": "desk"` (تلقائي للتصوير الطولي) | — |
| سالفة جانبية | تلقائي: `face_fx none` + شريط "على الهامش" | مزحة أو معلومة برا النص |
| اشتراك | تلقائي: `face_fx subscribe` | لما يطلب الاشتراك |
| كلام ورا ظهره | `face_cutout` `title` | كلمة الحلقة الكبيرة |
| شخصيته المرسومة | `avatar` | لحظات ما إلها صورة حقيقية |

## ملء الشاشة
| القطعة | بالخطة |
|---|---|
| صورة حقيقية بأشكال (دائرة، جريدة، بولارويد، لوحة دبابيس، تلفزيون قديم) | `image` |
| شريط صورة وورقة تنطبع | `image` `treatment: "band"` |
| أرشيف متحرك بإطار مدور | `footage` `treatment: "rounded"` |
| كلمة كلمة بتوقيت الكلام | `graphic kinetic` |
| رقم، عنوان، اقتباس، خريطة، خط زمني، رسم بياني، مطر عناوين، أشخاص بدال الرقم | `graphic` |
| قبل وبعد لنفس المكان (ورق ينشگ والسنين تعد) | `graphic custom` `scene: "FactoryEvolution"` |
| بطاقة شخص بصورته الحقيقية | `entity` (الأسماء تنصلّح لحالها بمرحلة `names`) |

## الانتقالات (إلها سبب من القصة)
`shutter` باب كراج (ورشة، مصنع)، `slide` ورقة تنسحب (دفتر، ملف)، `tear` ورق ينشگ (كشف)، `burn` ورق يحترق (نهاية، خسارة)، `dive` غوص (تفاصيل أعمق)، `pan` سحبة (مكان لمكان)، والباقي قطع مباشر.
