# ملفات التحديث (Style updates)

قرار صاحب القناة (2026-10-04): الستايلات **تنضاف ما تنمسح**. كل ما يلگه ستايل يعجبه (صور وفيديوهات بفولدر درايف)، Claude يحللها كلها ويكتب **ملف تحديث جديد** هنا.

- كل ملف = تحديث واحد، اسمه بالتاريخ: `YYYY-MM-DD-<وصف>.md`.
- الأساس يبقى `editor/styles/channel-system.md`، وملفات التحديث تنضاف فوگه بالترتيب. إذا تحديث أحدث يناقض قديم، **الأحدث يغلب** بس بالنقطة الي يذكرها.
- كل ملف بيه: المصدر (رابط الفولدر)، والستايلات الي انلگت (ويه أرقام الصور والفيديوهات)، وشنو موجود عدنا، وشنو انبنى جديد، وقواعد الاستخدام.
- صور وفيديوهات المراجع **ما تنرفع للريبو** (الريبو عام، وهي مال ناس ثانيين). بس أسماء الملفات ووصفها.
- المونتير (`.claude/skills/editor/SKILL.md`) يقرا كل ملفات هذا المجلد قبل ما يكتب الخطة.
