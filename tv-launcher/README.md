# شاشة عبود: واجهة تلفزيون بستايل آبل تي في

شاشة رئيسية جديدة لتلفزيونات أندرويد وگوگل تي في.

- **خفيفة:** حجمها ~40 كيلوبايت (الواجهات العادية عشرات الميگابايتات).
- **بدون إعلانات** وبدون أي اقتراحات أو أفلام تتحمل بالخلفية.
- **ما تستخدم الإنترنت نهائياً:** ما عدها صلاحية النت أصلاً، فكل سرعة نتك تروح للتطبيق الي تشوف بيه (مباريات، بث مباشر).
- **عربي وإنگليزي:** زر فوگ يبدل اللغة، وتنقلب الواجهة يمين ويسار.
- التطبيقات الي تفتحها أكثر تصعد أول.
- ضغطة طويلة على أي تطبيق: تفتح معلوماته (منها تحذفه).

## التنصيب على التلفزيون

1. نصّب تطبيق **Downloader** من متجر گوگل بلاي بالتلفزيون.
2. افتحه واكتب هذا الرابط:
   `https://github.com/Aboodkhalid23/Aboodi23/raw/claude/project-thread-4ztr10/tv-launcher/release/AboodTV.apk`
3. وافق على "تثبيت من مصادر غير معروفة" إذا سألك.
4. اضغط زر الرئيسية (البيت) بالريموت، واختار **شاشة عبود** ودائماً (Always).

> بأجهزة **Google TV** الجديدة، النظام ما يسأل وما يخليك تبدل الشاشة الرئيسية بسهولة. هناك تفتحها من قائمة التطبيقات، أو نسوي خطوة إضافية بالكمبيوتر.

## البناء (للمطورين)

```bash
ANDROID_HOME=/opt/android-sdk ./build.sh   # يطلع build/AboodTV.apk
```
يحتاج بس Java 17+ وأدوات أندرويد (build-tools 35 وplatform 34). ماكو Gradle ولا مكتبات خارجية.
`debug.keystore` مفتاح تجريبي عام (كلمة السر android) مو سر، موجود حتى كل تحديث ينصب فوگ القديم.
